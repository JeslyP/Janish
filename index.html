Magic rules to remember

Minus outside brackets flips the signs inside

−(5 − 3x) turns into −5 + 3x.

Divide by a minus number? Flip the sign!

≥ turns into ≤, and > turns into <.

Slope is rise over run

1/3 means go up 1, then right 3. Like climbing stairs.

x = a number is a wall

It stands straight up and down, like x = −4 or x = 5.

y = a number is a floor

It lies flat, side to side, like y = −1 or y = −3.

Filled dot or empty dot?

≤ or ≥ gets a filled dot (the number counts). < or > gets an empty dot (it doesn't).
